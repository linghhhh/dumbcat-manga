## 二、下载为什么在手机上不能用（根因）

1. **下载任务从来没被提交过**：作品页底部的「📥 下载」按钮只调用 `togglePickMode()` 切换勾选模式，
   `openDownloadForSelection()` 虽然写好了却没有任何 UI 绑定；`#downloadSelBtn` 从未被创建。
   手机上看到的就是「点了没反应」。
2. **Manifest 缺存储权限**：没有 `MANAGE_EXTERNAL_STORAGE`、`READ_EXTERNAL_STORAGE`，
   也没有 `requestLegacyExternalStorage`，Android 10+ 写公共目录必然失败。
3. **默认目录在应用私有区**：`getExternalFilesDir()` 落在 `Android/data/...`，
   文件管理器里翻不到，用户以为没下载。
4. **旧的 web.json 会永久沿用不可写目录**，没有回落逻辑，也不报错。
5. **下载历史永远为空**：`download_task` 表同一个 id 先写 `state='pending'`，
   写历史时主键冲突被吞掉。
6. 其它误报：空章节被结算成「完成 0 张」；404 / 付费章没有可读原因；
   `/api/choose-folder` 在安卓固定 501；`/api/export` 报 500 原始异常。

## 三、改了什么

### 阅读器
- `web/js/reader.js`（790 → 638 行）：删 `MODES / state.mode / showSingle / handleSwipe /
  toggleMode / applyModeStyles / 顶栏章节 select / 底栏模式与适应宽度按钮 / dblclick 切单页`；
  新增 `imgTop()`，断点续读与页码改用 `getBoundingClientRect()` 计算。
- `web/css/components.css`：`.reader-pages` 去掉 gap / 左右 padding / 字体行高影响，
  `.reader-pages img` 宽 100%、`display:block`、margin/border/padding 全 0；删掉单页与
  `[data-fit]` 规则。
- `web/js/viewer.js`（291 行重写）：去掉 `isSingle()` 闸门，双击 2× / 双指缩放 /
  Ctrl+滚轮在条漫下都可用；`imgAt()` 用 `elementFromPoint` 按坐标找图；放大后拖动平移，
  1× 时不拦截页面滚动；`is-zoomed` 类控制横向溢出。
- `web/js/settings.js`：删掉已失效的「图片间距」滑块。

### 书架 / 下载
- `web/js/shelf.js`：三个分段标签「📚书架 / 🕘浏览历史 / 📥下载缓存」，标题与副标题随标签变化，
  `#/shelf?tab=downloads` 可直达；下载模块挂在常驻容器上，切走退订 SSE。
- `web/js/downloads.js`：队列 / 历史 / 保存位置卡；安卓「选择文件夹…」走 App 内目录浏览
  （`/api/fs/dirs`）；首次使用先弹「所有文件访问权限」引导（`POST /api/storage/permission`）；
  已完成任务从队列移除、只在历史里出现；「导出到手机」在任务卡和历史行都可见。
- `web/js/detail.js`：底部下载按钮改成「勾选模式里有选中章节 → 提交任务；没选中 → 提示先选」。
- `web/js/app.js`：`/downloads` 旧路由重定向到 `#/shelf?tab=downloads`；
  `mine.js` / `settings.js` 的下载入口一并改到下载缓存标签。
- `web/css/downloads-tab.css`（新增）：窄屏 grid 子项 `min-width:0`、操作条换行、
  授权提示行样式。

### 安卓 / 后端
- `AndroidManifest.xml`：新增 `MANAGE_EXTERNAL_STORAGE`、`READ_EXTERNAL_STORAGE`
  （maxSdk 32）、`requestLegacyExternalStorage`。
- `MainActivity.java`：静态 `hasStorageAccess / storagePermissionKind /
  canRequestStorageAccess / requestStorageAccess / externalStorageRoot`；
  API 30+ 拉系统「所有文件访问」页，23–29 申请运行时写权限。
- `DownloadService.java`：前台服务启动失败时 `stopSelf()`，避免 ANR。
- `android_main.py`：启动时校验 `output_dir` 可写性并自动修正；新增 `DUMBCAT_APP_OUTPUT`；
  `APPDATA_VERSION` 升到 16（升级后强制重解压网页资源）。
- `server/download_paths.py`（新增）：`resolve_output_dir()` 逐级回落
  （用户选目录 → 公共 `呆猫漫画/` → 应用私有目录），不可写给出中文原因。
- `server/android_storage.py`（新增）：权限探测与申请，桌面上安全回落。
- `server/tasks.py`：提交与执行前都校验目录；修下载历史 UNIQUE 冲突；
  修「完成 0 张」「全 404 没原因」的结算；`output_note` 记录回落原因。
- `server/app.py`：`/api/choose-folder`、`/api/fs/dirs`、`/api/storage/permission`
  在安卓走真实路径；`/api/export` 报错改中文。

## 五、还需要你在真机上确认（我这边没有可用设备）

1. 装 `dist/呆猫漫画-0.2.1-v11.apk`（覆盖安装即可，数据保留）。
2. 打开「书架 → 下载缓存」→「更换…」→ 系统跳「所有文件访问权限」→ 打开 → 返回。
3. 再点「更换…」应能浏览目录，选到 `Download` 或任意文件夹。
4. 找一本免费漫画 → 勾章节 →「开始下载」→ 看进度走完、文件出现在你选的文件夹里。
5. 杀进程重开，确认队列能续跑、历史还在。
