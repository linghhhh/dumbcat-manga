# 呆猫漫画 安卓版 · 书架改造规范（v1）

> 本文件是本次改造的**唯一接口契约**。前端（web/**）由 Lead 实现；后端由 backend-shelf
> 实现；禁漫切条还原由 jm-scramble 实现；构建与模拟器验证由 build-verify 实现。
> 任何一方发现契约需要改动，先通知 Lead，由 Lead 更新本文件。

## 0. 需求（用户原话）

1. 抽屉里**只保留「图源」列表**，发现 / 搜索 / 下载 / 图源插件 / 设置 五个入口全部去掉。
2. 底部「下载」改成**「书架」**：可建**多个**书架，用户能自建；登录图源账号后**自动获取该图源
   的收藏**；用户在本机收藏的作品能**同步到图源收藏夹**；图源没有收藏能力就只存本地书架；
   另外要有**浏览历史**。
3. 禁漫天堂阅读图片错乱（切条乱序）在安卓上仍未修复，`呆猫漫画v3` 已修好，要同步过来。
4. **APK 里不能带任何用户账号信息**；老版本用户升级安装后，已登录的账号与书架里的收藏要还在。

## 2. 存储

- 路径：`dumbcat.app_config.APP_CONFIG_DIR / "shelves.json"`。
  安卓上即 `files/config/DumbCatManga/shelves.json` —— 这一层**升级不删**（`files/appdata`
  才会被 `APPDATA_VERSION` 变化整体删掉），所以书架必须放这里。
- 格式（JSON，UTF-8，原子写：先写 `.tmp` 再 `os.replace`，进程内 `threading.Lock`）：

```json
{
  "version": 1,
  "migrated": true,
  "shelves": [
    {"id": "s_xxx", "name": "我的书架", "kind": "local", "source": "",
     "created": 1763800000, "updated": 1763800000}
  ],
  "items": [
    {"id": "i_xxx", "shelfId": "s_xxx", "uid": "18comic:123456", "source": "18comic",
     "key": "18comic", "title": "…", "cover": "…", "author": "…", "tags": [],
     "url": "", "added": 1763800000,
     "remote": "synced"}
  ],
  "history": [
    {"uid": "18comic:123456", "source": "18comic", "title": "…", "cover": "…",
     "chapterUid": "18comic:123456:c1", "chapterTitle": "第1话", "page": 3,
     "total": 24, "ts": 1763800000}
  ]
}
```

规则：
- `kind`: `"local"`（用户自建）或 `"source"`（登录图源后自动生成，`source` 填图源 key）。
- 同一个书架里 `uid` 不重复；同一 `uid` 可以同时存在于多个书架。
- `remote`: `"synced"` / `"unsupported"` / `"not-logged-in"` / `"failed"` / `""`。
- 首次加载（store 不存在或 `migrated` 不为 true）时**自动**创建一个 `local` 书架
  「我的书架」作为默认架，`id` 固定为 `s_default`。
- `source` 书架每个图源最多一个（`id` 固定 `s_source_<key>`），拉取收藏时按 uid 增量合并
  （远端没有的条目标记 `remote:"removed"` 并从该架删除；不要动 local 架）。
- 浏览历史每个 `uid` 只留一条（最新的覆盖旧的），最多保留 500 条，按 `ts` 倒序返回。

## 3. HTTP 接口（全部挂在现有 FastAPI app 上，沿用现有 token 校验中间件）

统一响应：成功 `200` + JSON；未登录图源相关错误 `400` + `{"detail": "…"}`（中文，前端直接提示）。

### 3.1 `GET /api/shelf`
返回书架列表 + 默认架 + 图源账号/收藏能力状态。

```json
{
  "shelves": [{"id": "s_default", "name": "我的书架", "kind": "local", "source": "",
               "count": 12, "created": 0, "updated": 0}],
  "defaultShelfId": "s_default",
  "sources": [{"key": "18comic", "name": "禁漫天堂", "supportsFavorites": true,
               "loggedIn": true, "username": "<账号名>", "shelfId": "s_source_18comic"}],
  "historyCount": 30
}
```

- `sources` 只列**支持官方收藏**的图源（`provider.supports_favorites()` 为真）。
- `loggedIn` 用 `provider.is_logged_in()`；`username` 取自会话（取不到就 `""`）。
- 该接口必须快（不允许同步网络请求超过 ~1.5s，`is_logged_in` 本身有 60s 缓存）。

### 3.2 `POST /api/shelf/create` `{name}` → `{"shelf": {...}}`
名字去空白；空名字自动「书架 2、书架 3…」；重名允许。

### 3.3 `POST /api/shelf/rename` `{id, name}` → `{"shelf": {...}}`

### 3.4 `POST /api/shelf/delete` `{id}` → `{"ok": true}`
`kind == "source"` 的书架**不能删**：返回 400 `{"detail":"图源书架不能删除，可以先退出图源账号"}`。

### 3.5 `GET /api/shelf/items?shelfId=xxx` → `{"items": [...]}`（`shelfId` 省略=全部）

### 3.6 `POST /api/shelf/add` `{shelfId, uid, source, series}` → `{"item": {...}, "remote": "...", "shelf": {...}}`
- `series` 是 `/api/series/{uid}` 那套 dict（至少含 `title`、`cover`、`author`、`tags`、`url`；
  禁漫的官方收藏需要 `id`/`slug`，`series` 里有就带着）。
- 已存在 → 幂等返回已有 item。
- 写入后，若该图源 `supports_favorites()` 且 `is_logged_in()`，**同时**调
  `provider.add_favorite(series, folder)` 推到官方收藏夹：成功 `remote="synced"`；
  抛 `FavoritesUnsupported` → `"unsupported"`；`LoginRequired` → `"not-logged-in"`；
  其它异常 → `"failed"`。**远端失败不能让本地保存失败**。
- 网络调用用 `await asyncio.to_thread(...)`，并设总超时 ~20s。

### 3.7 `POST /api/shelf/remove` `{shelfId, uid}` → `{"ok": true, "remote": "..."}`
- 如果该 `uid` **不再属于任何书架**，且图源支持收藏且已登录 → 调 `remove_favorite`。
  仍被别的书架引用则不碰远端（`remote="kept"`）。
- 失败规则同 3.6。

### 3.8 `POST /api/shelf/sync` `{source}` → `{"shelf": {...}, "added": 3, "removed": 0, "total": 25, "at": 1763800000}`
- 未登录：400 `{"detail":"还没登录禁漫天堂"}`。
- `supports_favorites()` 为假：400 `{"detail":"禁漫天堂不支持官方收藏夹"}`。
- 拉 `provider.favorite_series("")`，写/更新 `s_source_<key>` 书架（`kind:"source"`，
  `name` 用 `provider.display_name + " 收藏"`），`remote="synced"`。
- 该书架已存在时按 uid 增量合并：新增的加入、远端已没有的移除（`removed` 计数）。
- 有网络，允许 5~60s，前端会显示 loading。

### 3.9 `GET /api/shelf/status?uid=xxx` → `{"shelves": [{"id","name"}], "saved": true}`
详情页按钮用：该作品在哪些书架里。

### 3.10 `GET /api/shelf/history?limit=100` → `{"items": [...]}`

### 3.11 `POST /api/shelf/history` `{uid, source, title, cover, chapterUid, chapterTitle, page, total}` → `{"ok": true}`
阅读器每次打开章节 / 翻页时上报（前端会节流）。缺 `uid` 就 400。

### 3.12 `POST /api/shelf/history/clear` → `{"ok": true, "removed": n}`

### 3.13 `POST /api/shelf/history/remove` `{uid}` → `{"ok": true}`

## 4. 升级迁移（老用户不丢东西）

1. **登录态**：本来就在 `files/config/DumbCatManga/sessions/*.json`，不动即可保留。
2. **旧下载记录**：旧版在 `files/appdata/.DumbCatMangaRuntime/web/downloads.json`
   （= `server.tasks.HISTORY_PATH`），而 `APPDATA_VERSION` 一变，`files/appdata` 会被整体删除。
   所以在 `android_main._extract_appdata()` 删除**之前**，把
   `files/appdata/.DumbCatMangaRuntime/web/downloads.json` 复制到
   `files/config/DumbCatManga/legacy_downloads.json`（已存在就不覆盖）。
3. 后端首次加载 store 时（`migrated != true`）读 `APP_CONFIG_DIR/legacy_downloads.json`，
   把里面的作品写进一个 `local` 书架「旧版下载」（`id` 固定 `s_legacy`，没有内容就不建），
   然后把 `migrated` 置 true 落盘。迁移失败只打日志，不能影响启动。

## 5. 前端行为（Lead 实现，供 backend 参照）

- 抽屉：品牌 + 「图源」列表 + 版本号；`.nav` 整个删掉。
- 底部 tab：发现 / 搜索 / **书架** / 我的。
- 书架页（`#/shelf`）：
  - 顶部「书架」+「+ 新建书架」；
  - 图源账号卡：未登录显示「登录禁漫天堂」（账号密码登录 + Cookie 登录两种入口），
    登录成功后自动调 `POST /api/shelf/sync`；已登录显示账号名 + 「同步收藏」+「退出登录」；
  - 书架 chips 横滑切换，长按/「…」可重命名/删除；
  - 条目网格（封面 + 标题 + 作者），点击进详情，条目「…」可移除；
  - 「浏览历史」入口 → 历史列表，可清空、单击续读。
- 详情页：加「收藏」按钮 → 弹书架多选（可现场新建）→ `POST /api/shelf/add`；
  已是收藏状态显示实心并允许移除。
- 阅读器：打开章节 / 翻页时 `POST /api/shelf/history`（1~2s 节流）。
- 下载队列接口保留不动（不做 UI 入口也不删后端）。
